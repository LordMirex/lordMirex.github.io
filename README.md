# LordMirex Portfolio

Personal portfolio site for LordMirex, focused on full-stack and backend engineering work. The site highlights background, skills, featured projects, experience, education, and contact details.

## Highlights
- Single-page layout with smooth in-page navigation.
- Responsive header menu for mobile and desktop.
- Dedicated projects section for showcasing work.

## Featured Projects
- **SuperFast cPanel Transfer** — Production-grade PHP utility for secure FTP file migration.
- **MyTypist (SaaS Product)** — SaaS writing and productivity platform with structured workflows.
- **Backend System / API Services** — Laravel systems with authentication, admin controls, and REST APIs.
- **ECOREWIRE Platform** — PHP platform for ECOREWIRE NGO ecosystem restoration operations.  
  Repository: https://github.com/LordMirex/ecorewire

## Tech Stack
- HTML5
- CSS3
- Vanilla JavaScript

## Local Preview
Open `index.html` directly in your browser, or use a simple local server:
```bash
python -m http.server
```
Then visit `http://localhost:8000`.

## Customize
- Update content in `index.html`.
- Adjust styling in `style.css`.
- Navigation behavior lives in `script.js`.
